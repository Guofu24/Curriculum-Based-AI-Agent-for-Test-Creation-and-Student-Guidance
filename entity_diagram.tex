\vspace{0.5cm}

\noindent\textbf{Notes}
\begin{itemize}
  \item The diagram includes only persistent entities that exist in the current code under \texttt{backend/app/models}.
  \item \texttt{course\_id} exists in \texttt{Document} as a nullable UUID field, but there is no \texttt{Course} entity or foreign key in the current code.
  \item Several exam business objects are stored in JSONB instead of separate tables, such as \texttt{scope}, \texttt{exam\_config}, \texttt{questions}, and \texttt{blueprint}.
  \item \texttt{reviewed\_by\_human} is shown as \texttt{VARCHAR(5)} because that is how it is currently mapped in the model code.
\end{itemize}
